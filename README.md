# EEFE 530 – Applied Econometrics II: Causal Inference

Instructor: Daniel Brent  
Email: dab320@psu.edu

## Course Description
This course prepares PhD students to estimate causal parameters using modern econometric methods, with an emphasis on causal inference in applied economics.

## Topics
- Potential outcomes framework
- Selection on observables (matching / weighting)
- Instrumental variables
- Difference-in-differences
- Synthetic control
- Regression discontinuity
- Experiments
- Machine learning methods for causal inference
